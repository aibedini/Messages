# Messages v2.6.39

Fixes Android ↔ GMweb pairing identity bootstrap and ordering.

- Scans the QR before enrollment so Android receives the short-lived,
  session-bound bootstrap capability generated by an authenticated GMweb
  dashboard session.
- Registers or refreshes the Android identity before signed metadata lookup.
- Existing enrolled identities refresh with `X-Agent-Auth`; the unrelated
  local `gw_` REST key is no longer sent as the GMweb enrollment credential.
- Retries `unknown_device` once with a fresh timestamp/signature and never
  retries signature, replay, timestamp, or malformed-header failures.
- Keeps the UI out of Trusted/Linked until server approval returns HTTP 200.
- Stops logging raw QR content, which can contain the one-time capability.

Required server counterpart: GMweb v0.13.10 or newer.
