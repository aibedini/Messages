# Messages v1.2.2

This release fixes the onboarding continuation flow and polishes the core messaging UI.

## Highlights

- The privacy disclosure button now immediately advances to the Default SMS role step.
- Onboarding state stays synchronized when returning from Android Settings or permission dialogs.
- Loading and empty states are calmer and accessible, without an infinite spinner animation.
- Search, top-bar actions, default-app guidance, and gateway consent surfaces now use one consistent green/charcoal visual system.
- Gateway privacy copy and switch semantics are clearer; gateway behavior remains opt-in.

The APK is signed with the project's existing release key. Play Protect may still review or block sideloaded SMS apps distributed outside Google Play; this release does not disable or bypass that security feature.
